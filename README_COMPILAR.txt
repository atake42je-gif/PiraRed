PIRARED ANDROID — PROYECTO PARA GENERAR APK

Este es un proyecto Android Studio que envuelve el prototipo web en una aplicación Android (WebView).
Todavía NO es un APK compilado.

PARA COMPILAR:
1. Abrir el proyecto en Android Studio en una computadora.
2. Esperar la sincronización de Gradle.
3. Ir a Build > Build Bundle(s) / APK(s) > Build APK(s).
4. El APK de prueba se genera normalmente en app/build/outputs/apk/debug/app-debug.apk.

Si solo tenés celular Android:
- Este ZIP es el código fuente. No se compila por abrirlo en Chrome.
- Podés usar un servicio de compilación Android compatible o una computadora con Android Studio.
- No compartas claves ni contraseñas de firma con terceros.

LIMITACIONES:
- Incluye interfaz y datos de demostración.
- El perfil se guarda localmente en el dispositivo.
- No hay backend, cuentas reales, mensajería ni publicaciones reales.
- Las imágenes remotas requieren conexión a Internet.
- No activar operaciones de cajeros/pagos hasta validar legalidad y proveedor autorizado.
